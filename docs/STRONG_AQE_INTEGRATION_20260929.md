# Strong L336 + пакетный AQE: интеграция

Текущий исследовательский результат зафиксирован в родительском рабочем
проекте, `reports/strong_l336_aqe_20260929.md`. Здесь описан контракт
кода, а не официальная оценка жюри.

## Два режима одной галереи

- `/solo` → `/api/infer` → `/v1/search`: один исходный JPEG/PNG и BBox,
  энкодер strong L336, exact cosine и версия strong-политики отказа.
  Transductive AQE здесь **не применяется**.
- `/many` → `/api/infer-batch`: ZIP либо набор файлов плюс BBox CSV. Каждый
  кадр извлекается/декодируется отдельно, возвращает 1024D L2-вектор;
  валидные векторы отправляются **одним cohort** в `/v1/search-batch`.
  Режим `transductive_aqe_k5_alpha025` расширяет запросы и галерею вместе.
  Повреждённый кадр получает ошибку и не участвует в cohort; порядок
  результатов/имена файлов сохраняются.

Ответ `ranked` упорядочен по `ranking_score` AQE. Поля `similarity` и
`confidence` — **исходный cosine, не вероятность**. `accepted`/`candidates`
отвечают за отдельный механизм отказа на AQE-selected top10; политика
получает raw cosine, отсортированный внутри по cosine, и затем результат
сопоставляется обратно AQE-рангу. В ответе есть `ranking_algorithm` и
`query_cohort_size`. Граница модели проверяется по `model_version` и SHA;
галерея от mild-веса несовместима со strong.

Экспорт сдачи использует тот же пакетный AQE. В `embeddings.npy` записаны
AQE-уточнённые FP32-векторы (`test_query.csv`, затем `test_gallery.csv`),
так что cosine по файлу воспроизводит `submission.csv`. Политика отказа
для `candidates.csv` получает raw cosine **до** AQE. Манифест экспорта
маркирует обе семантики; старый cosine-режим остаётся доступен по
`batch_ranking=exact_cosine`. Отсутствие официального скрипта означает,
что принятие transductive-представлений нельзя заранее гарантировать.

## Артефакт и локальный запуск

Новый вес и portable policy пользователь скачал в исследовательский
каталог `../data/derived/strong_l336_20260929/`. Локальный release-bundle
скопирован в `model_artifacts/strong_l336_aqe/`; вес там —
1 217 580 060 байт, SHA256
`de955ba6ec3a2cb232708eddd1b1b57400bc449405d6d9e2ab25c791a46e617f`.
Манифест лежит рядом. Для полного runtime также нужны версия strong
`boosting_policy.json` (SHA
`55f22986118c25c6cf57f4489605c525f3b198a417d4fad1994d093f742f5f8b`)
и соответствующий `calibration_manifest.json`; обе SHA и версия
проверены локально. `bundle_manifest.json` содержит SHA и размеры всех
четырёх runtime-файлов. `quick_start.py` и Compose по умолчанию читают
этот новый bundle; другой можно выбрать через абсолютный
`LCT_ML_ARTIFACT_DIR`. Вес в Git LFS локально подготовлен, но push
пока не сделан. Не передавать веса через CULAB; сервер без интернета.

При обновлении модели ранее сохранённые эмбеддинги общей галереи нельзя
повторно использовать. Загрузите её исходные кадры+BBox заново либо
выполните отдельное версионированное переиндексирование, сохранив оригиналы
и старый индекс для отката. Стартовая новая установка имеет пустую общую
галерею, затем оба режима используют один её ID.

## Проверенные и открытые gates

Проверено локально: SHA strong-веса, strict CPU load, нормированный 1024D
вектор, соответствие формулы AQE reference-тесту и round-trip
AQE `embeddings.npy`→`submission.csv`, 58 backend тестов и
11 frontend тестов. Дополнительный smoke с настоящим весом на
10 исходных JPEG+BBox галереи и 2 запросах дал нормированные матрицы
`10×1024` и `2×1024`, AQE top-10 без ошибки. Полный
strong+policy+галерея E2E прошёл в изолированной локальной среде:
галерея 10/10, пакетный ZIP и отдельные файлы — 2/2 HTTP 200,
top-10/accepted совпали; solo использовал cosine. Не проверено:
Windows/Docker/GPU, peak RAM/latency для реального потока, миллионная
галерея, скрытый тест. Exact AQE по cohort требует квадратичного числа
сравнений; chunking ограничивает промежуточную RAM, но не делает метод
пригодным для 10⁶ объектов без отдельного ANN-проекта. Веса энкодера
<2 ГБ, но сохранённые изображения/галерея — отдельный объём данных.

Официальный скрипт и hidden-test результат недоступны; внутренние
dev/calibration цифры нельзя выдавать за конкурсный балл.
