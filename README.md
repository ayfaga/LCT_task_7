# LCT Case Championship Project

Этот проект представляет собой минимальный CRUD REST API и landing page для загрузки изображений и запуска симуляции инференса модели.

## Запуск

```bash
docker compose up --build
```

После запуска:
- Frontend: http://localhost:8000/
- API docs: http://localhost:8000/docs
- PostgreSQL: localhost:5432

## Основные команды

```bash
docker compose down -v
docker compose logs -f backend
```
